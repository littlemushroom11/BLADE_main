# BLADE

Table 3 / Table 5 additional seeds: see [MULTISEED_README.md](MULTISEED_README.md)
for the five server scripts, command-line dataset/output/checkpoint paths,
shared results, and five-seed aggregation.

Research code for studying backdoor attacks against image-classification models
in simulated split learning. The implementation separates a model into a client
and a server, freezes the clean client after training, estimates an
input-to-latent trigger direction from black-box smashed-feature queries, and
then trains only the original server with poisoned cached features.

This repository is intended for reproducible academic research on public
datasets. It does not contain code for attacking deployed systems.

## Method overview

The experiment consists of two stages:

1. **Clean model training.** Train a full ResNet-18 and export equivalent
   client/server checkpoints for the requested split points.
2. **Attack training.** Load a clean split checkpoint, freeze the client,
   collect clean feature statistics, estimate the latent direction `delta` for
   one configured input trigger, and fine-tune the server with poisoned cached
   smashed features.


## Repository structure

```text
BLADE/
  attack.py             Trigger-to-latent calibration
  datasets.py           Dataset loading and preprocessing
  models.py             Split model definitions
  run_experiment.py     Attack-training entry point
  train_clean_bank.py   Clean ResNet-18 training and split export
  training.py           Clean, cached-feature, and evaluation routines
  triggers.py           Input-trigger implementations
configs/                Reproduction configurations
data/                   Local datasets (not generated by the code)
outputs/                Checkpoints, metrics, and visualizations
```

Run all commands from the repository root so that Python can import the `BLADE`
package and relative paths in the configurations resolve correctly.


## Datasets

- **CIFAR-10, CIFAR-100, and GTSRB** are downloaded automatically through
  `torchvision`.
- **PathMNIST** expects `data/pathmnist_64.npz` with the standard
  `train_images`, `train_labels`, `test_images`, and `test_labels` arrays.
- **Tiny ImageNet** expects the extracted dataset at
  `data/tiny-imagenet-200/`.

Dataset roots can be changed through `dataset.data_dir` in the YAML files.

## Reproducing the experiments

### 1. Train the clean base model

Train the CIFAR-10 base model:

```bash
python -m BLADE.train_clean_bank \
  --datasets cifar10 \
  --output-dir outputs/clean_resnet18_bank \
  --device cuda 
```

The early-split checkpoint used by the CIFAR-10 attack configuration is written
to:

```text
outputs/clean_resnet18_bank/cifar10/cifar10_resnet18_split_early_best.pt
```

Other supported base models can be trained with:

```bash
# Train one dataset
python -m BLADE.train_clean_bank --datasets cifar100 --output-dir outputs/clean_resnet18_bank
python -m BLADE.train_clean_bank --datasets gtsrb --output-dir outputs/clean_resnet18_bank
python -m BLADE.train_clean_bank --datasets pathmnist --output-dir outputs/clean_resnet18_bank
python -m BLADE.train_clean_bank --datasets tinyimagenet --output-dir outputs/clean_resnet18_bank

# Train all available datasets sequentially
python -m BLADE.train_clean_bank \
  --datasets cifar10,cifar100,gtsrb,pathmnist,tinyimagenet \
  --output-dir outputs/clean_resnet18_bank
```

For a short pipeline check, add `--max-epochs 1`. Existing completed jobs are
skipped unless `--force` is supplied.

### 2. Run attack training

After the clean checkpoint has been generated, run the corresponding attack
configuration. For the main CIFAR-10 experiment:

```bash
python -m BLADE.run_experiment \
  --config configs/cifar10_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64_attack10_multisource_all_1pct_bs256.yaml
```

Commands for the remaining provided configurations:

```bash
python -m BLADE.run_experiment \
  --config configs/cifar100_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64_attack10.yaml

python -m BLADE.run_experiment \
  --config configs/GTSRB_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64_attack10.yaml

python -m BLADE.run_experiment \
  --config configs/pathmnist_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64_attack10.yaml

python -m BLADE.run_experiment \
  --config configs/tinyimagenet_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64_attack10.yaml \
  --output-dir outputs/tinyimagenet_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64
```

Each attack configuration sets `warmup_checkpoint.load_path` to a clean
checkpoint under `outputs/clean_resnet18_bank/`. Override it on the command line
with `--clean-checkpoint /path/to/model.pt`, and use `--data-dir /path/to/data`
and `--output-dir /path/to/results` for the other paths. The loader supports
this project's full ResNet-18 checkpoints and can repartition its clean split
checkpoints to early/middle/late without retraining.

Useful command-line overrides include:

```bash
python -m BLADE.run_experiment \
  --config configs/cifar10_resnet18_layer1_checkerboard_center_4x4_ratio10_carrier64_attack10_multisource_all_1pct_bs256.yaml \
  --seed 2 \
  --target-class 5 \
  --trigger-name noise_patch \
  --attack-epochs 10 \
  --output-dir outputs/cifar10_seed2_target5
```

Attack runs keep smashed-feature batches only as temporary training data. The
run removes its `smashed_feature_cache/` directory after training and retains
the JSON, CSV, PNG, and NumPy result files. It does not save attack-stage model,
feature-statistics, or calibration `.pt` files. Clean checkpoints produced by
`BLADE.train_clean_bank` remain in `.pt` format because they are required to
initialize the attack experiments. A cache supplied explicitly through
`reuse_cache_dir` is treated as external input and is not deleted.
